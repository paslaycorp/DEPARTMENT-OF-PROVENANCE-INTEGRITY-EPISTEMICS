# DPIE Conformance Tests

`pc-core-attack-vectors.json` is the machine-readable attack corpus for DPIE-PC-CORE-0.1.

A future reference implementation should consume these vectors and assert that no operation produces unjustified provenance strengthening.

The corpus is intentionally implementation-neutral: it specifies adversarial inputs and expected semantic outcomes without prescribing storage technology, programming language, database, or UI.
